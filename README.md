# Fake Komga Web Reader（已归档）

> **本项目已停止维护。** 原服务端 `fake-komga-115` 已更名为 [MangaAlpha](https://github.com/xJogger/MangaAlpha)，从 [v2.0.0](https://github.com/xJogger/MangaAlpha/releases/tag/v2.0.0) 起就内置了网页书架和阅读器，无需单独部署这个前端。

## 现在怎么用？

1. 安装或升级到 [MangaAlpha](https://github.com/xJogger/MangaAlpha/releases/latest)。
2. 用浏览器打开你自己的 MangaAlpha 服务地址，从内置书架选一本漫画即可阅读。

内置阅读器和服务端同源运行，不需要给旧独立前端配置跨域（CORS）。旧前端的部署说明不适用于 MangaAlpha v2 及更新版本。

本仓库保留源码和提交历史供参考，不再更新。
